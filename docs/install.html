Installing & running it

No programming experience needed. You'll install one small free tool, download the project, and run a single command. Budget about 10 minutes the first time. The app then runs entirely on your own computer — nothing is uploaded anywhere.

What you need

A Windows, macOS or Linux computer, an internet connection (to download the tool and, later, to fetch card data from Scryfall), and a web browser. You do not need to install Python yourself — the tool below does that for you.

Step 1 — Install uv

uv is a tiny tool that runs the project and automatically fetches the correct version of Python and every dependency, so you never have to manage that yourself. Open a terminal and paste one line:

Your computerOpen a terminal by…Paste this, then press Enter
macOSpress ⌘ + Space, type “Terminal”, Enter curl -LsSf https://astral.sh/uv/install.sh | sh
Linuxopen your terminal app curl -LsSf https://astral.sh/uv/install.sh | sh
WindowsStart menu, type “PowerShell”, Enter powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

When it finishes, close and reopen the terminal so it picks up the new uv command. (Prefer a package manager? uv is also on Homebrew (brew install uv) and the Microsoft Store / winget — see uv's site.)

Step 2 — Download the project

Easiest, no Git required: on the GitHub page click the green “<> Code” button, then “Download ZIP”. Unzip it somewhere you'll find again (e.g. your Documents folder). You'll get a folder named MtG-Goldfish-Simulator-main.

Comfortable with Git? git clone https://github.com/BastienPasdeloup/MtG-Goldfish-Simulator.git works too.

Step 3 — Run it

In the terminal, move into the folder you just unzipped, then start the app. A handy trick for the first line: type cd and a space, then drag the folder onto the terminal window (it fills in the path for you) and press Enter. Then run the second line:

cd path/to/MtG-Goldfish-Simulator-main
uv run mtg-goldfish        # first run downloads Python + dependencies — a minute or two

When you see a line like Uvicorn running on http://127.0.0.1:8000, open that address in your web browser. That's it — the simulator is running.

  • To stop it: return to the terminal and press Ctrl + C.
  • To start it again another day: just repeat the two commands in Step 3.

Step 4 — Use it in the browser

  1. Paste a Moxfield or MTGTop8 deck URL. The format, commanders and companions are all detected automatically.
  2. Define properties (a trigger moment + a plain-English condition) and how many mulligans to allow.
  3. Compile, review the generated code, and run a simulation. Statistics stream live; each successful game can be replayed on an MTGO-like board, and its full search tree opened.
Optional: sharper English → code

Out of the box, a built-in offline converter handles simple conditions. For more complex English, click ⚙ Choose model in the Properties box to use a local model (via Ollama) or an API model — set an ANTHROPIC_API_KEY (copy .env.example to .env). Either way the generated code is shown for you to review before running.

Updating to a newer version

The project improves over time. On startup the app compares its version against the latest released on GitHub and shows a small “download the latest version” popup when a newer one exists. This works however you installed it — ZIP download or Git clone.

  • Downloaded the ZIP? Download the ZIP again and replace your folder (your saved sessions live elsewhere and aren't affected).
  • Cloned with Git? Run git pull in the project folder, then start it again with uv run mtg-goldfish.

Troubleshooting

SymptomFix
uv: command not found Close and reopen the terminal after Step 1. If it persists, re-run the install line and read its final notes about your PATH.
cd says “No such file or directory” The path is wrong — retype cd and drag the unzipped folder onto the terminal to fill it in exactly.
The browser page doesn't load Make sure the terminal still shows Uvicorn running… and open exactly http://127.0.0.1:8000.
A card is shown in red It has no dedicated implementation yet and plays as a vanilla approximation — results relying on it are approximate.
