🐞 Report a bug
  1. Download the session file — it contains the deck, the properties and the current run, and is essential to reproduce the problem.
  2. Open a new issue on GitHub — github issue page ↗
  3. Describe what happened, as specifically as possible:
    • what you did (which buttons, which settings, which seed);
    • which card / game / step is affected (game and step numbers help a lot);
    • what you expected, and what happened instead.
  4. Attach the downloaded file by dragging it into the issue description, then submit.
